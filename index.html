Questions? Answers.

How do I install the APK?

Tap Download APK on your Android phone, open the file when it finishes, and tap Install. That's it.

Why does Android warn me about "unknown apps"?

Android shows this for any app that doesn't come from the Play Store. Allow your browser to install apps when asked, then install as usual.

Is there an iPhone version?

Not yet. Both apps are Android-only for now.

Are these apps free?

Yes. Both were built as a university project and are free to try.

Where can I see the source code?

Each app has a public GitHub repository. You'll find the links in the footer.
